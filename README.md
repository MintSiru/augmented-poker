# 증강 홀덤 (Augmented Hold'em) 프로토타입

텍사스 홀덤에 "증강" 시스템을 더한 온라인 멀티플레이 프로토타입입니다.
친구들이 각자 기기의 브라우저로 접속해 최대 8명(빈자리는 봇)이 함께 플레이할 수 있습니다.
그래픽보다 **규칙의 정확성**과 **숨겨진 정보의 보안**을 우선했습니다.

- 언어: TypeScript (서버·클라이언트·엔진)
- 서버: Node.js + Express(정적 파일) + Socket.IO
- 클라이언트: 프레임워크 없는 웹 페이지 (Vite 빌드)
- DB 없음: 게임 상태는 서버 메모리에만 있습니다.

## 로컬 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
```

### 배포와 같은 방식으로 실행 (권장)

```bash
npm run build
```

```bash
npm start
```

브라우저에서 http://localhost:3000 을 엽니다. 다른 기기(같은 와이파이)에서는 `http://<내 컴퓨터 IP>:3000` 으로 접속할 수 있습니다.

### 디버그 모드로 실행

```bash
npm run build
```

```bash
DEBUG=true npm start
```

### 개발 모드 (코드 수정 시 자동 반영)

```bash
npm run dev
```

게임 서버(3000)와 Vite 개발 서버(5173)가 함께 뜹니다. 브라우저는 **http://localhost:5173** 으로 접속하세요 (Socket.IO 요청은 3000번으로 자동 전달됩니다).

### 여러 창으로 혼자 테스트하기

- 브라우저 창(또는 탭)마다 다른 플레이어로 입장할 수 있습니다. 자리 정보는 **탭마다 따로** 저장되므로, 새로고침하면 그 탭의 자리로 자동 복귀합니다.
- 브라우저를 완전히 닫았다가 다시 열면 첫 화면에 "이전 방의 내 자리로 돌아가기" 버튼이 나옵니다. (같은 브라우저의 다른 탭에서 이 버튼을 누르면 그 자리를 쓰던 탭은 끊깁니다.)

## Render 무료 웹 서비스로 배포하기

서버 하나가 클라이언트 정적 파일과 Socket.IO 를 함께 제공하므로, **웹 서비스 1개**만 만들면 하나의 주소로 접속과 게임이 모두 됩니다.

1. 이 폴더를 GitHub 저장소로 올립니다.
   ```bash
   git init
   ```
   ```bash
   git add -A && git commit -m "증강 홀덤 프로토타입"
   ```
   GitHub 에서 빈 저장소를 만든 뒤 안내에 따라 `git remote add origin ...` 과 `git push -u origin main` 을 실행합니다.
2. https://dashboard.render.com 에 로그인 → **New +** → **Web Service** 를 누릅니다.
3. **Build and deploy from a Git repository** 에서 GitHub 를 연결하고 방금 만든 저장소를 고릅니다.
4. 설정값을 입력합니다.
   | 항목 | 값 |
   |---|---|
   | Name | 원하는 이름 (주소가 `https://<이름>.onrender.com` 이 됨) |
   | Region | 가까운 곳 (예: Singapore) |
   | Branch | `main` |
   | Runtime | **Node** |
   | Build Command | `npm ci --include=dev && npm run build` |
   | Start Command | `npm start` |
   | Instance Type | **Free** |
5. **Advanced** 를 펼쳐 다음을 설정합니다.
   - Health Check Path: `/health`
   - Environment Variable: `NODE_VERSION` = `22` (저장소의 `.node-version` 파일로도 지정되어 있음)
   - **`DEBUG` 는 추가하지 마세요.** 설정하지 않으면 디버그 기능은 서버 코드에서 완전히 꺼집니다.
6. **Create Web Service** 를 누르면 빌드와 배포가 시작됩니다. 로그에 `증강 홀덤 서버 실행 중` 이 보이면 완료입니다.
7. 화면 위쪽의 `https://<이름>.onrender.com` 주소로 접속해 방을 만들고, "링크 복사"로 친구에게 공유합니다.

> 참고: 저장소에 있는 `render.yaml` 로 **New + → Blueprint** 를 선택해 같은 설정을 한 번에 만들 수도 있습니다.
> 서버는 Render 가 주는 환경 변수 `PORT` 로 포트를 받습니다. 클라이언트는 같은 주소로 Socket.IO 에 접속하므로 별도 서버 주소 설정이 필요 없습니다.

### 무료 등급 주의사항

- 일정 시간(약 15분) 접속이 없으면 서버가 **잠듭니다**. 그 뒤 첫 접속은 서버가 깨어나는 동안 **수십 초~1분 정도 느릴 수 있습니다.** 게임을 시작하기 전에 한 번 열어 두세요.
- 서버가 잠들거나 재시작(재배포 포함)되면 **진행 중인 게임과 방이 모두 사라집니다.** (게임 상태는 메모리에만 있음) 이때 화면에는 "재연결 중"이 표시된 뒤 첫 화면으로 돌아갑니다.

## 게임 방법

1. 첫 화면에서 닉네임을 입력하고 **방 만들기**(방 이름 최대 20자, 비우면 "○○님의 방" / 공개·비공개), **방 코드로 입장**(영문 대문자+숫자 5자리), 또는 **공개 방 목록**에서 입장.
   - 공개 방 목록은 실시간으로 갱신되며 방 이름, 인원, 상태(대기 중/게임 중), 중도 참여 가능 여부, 시작 칩, 시작 블라인드만 보입니다. 대기 중인 방이 위에 오고, 꽉 찼거나 중도 참여가 꺼진 게임 중인 방은 입장 버튼이 비활성화됩니다.
   - 비공개 방은 코드나 링크로만 들어갈 수 있습니다. 동시에 존재할 수 있는 방은 최대 50개입니다.
2. 방장은 대기실에서 설정을 정하고 **게임 시작**합니다.
   | 설정 | 범위 (기본값) |
   |---|---|
   | 최대 인원 | 2~8 (8) |
   | 빈자리 봇 채우기 · 봇 수 | 끄기 |
   | 행동 제한 시간 | 15~60초 (30초) |
   | 시작 칩 | 200~10,000 (1,000). 옆에 BB 배수 표시, **10BB 미만이면 시작 불가** |
   | 시작 블라인드 | BB 2~1,000 (20), SB 는 절반 |
   | 블라인드 상승 주기 | 자동 = 그 레벨이 시작될 때 남은 인원 × 2핸드 (기본) / 고정 4~30핸드 |
   | 블라인드 상승 방식 | 기본 표 = BB 1→2→4→7.5→15→30→60배 → 이후 2배씩 (기본) / 1.5배씩(보기 좋은 숫자로 반올림) |
   | 중도 참여 | 켜기 (기본) / 끄기 |
   | 연결 끊긴 플레이어 자동 추방 | 끄기 / 3분 / 5분 (기본) / 10분 |
   | 재충전 선택 | 끄기 (기본) / 켜기 |
   | 증강 리롤 | 1인당 게임 전체 0~3회 (2회) |
   | 공개 여부 | 대기실·게임 중 언제든 변경 |

   게임이 시작된 뒤에는 상단 **방 설정** 버튼으로 최대 인원·제한 시간·중도 참여·자동 추방·공개 여부·**블라인드 상승 주기**(다음 레벨부터 적용)만 바꿀 수 있고, 시작 칩·블라인드·상승 방식·재충전 선택·증강 리롤은 잠깁니다.
3. 게임 시작 때와 블라인드가 오를 때마다 증강 3개 중 1개를 고릅니다(30초, 시간이 지나면 무작위).
   - **🎲 리롤**: 선택지 3개를 같은 레벨 확률로 새로 뽑습니다(지금 보이던 증강은 빠짐). 횟수는 게임 전체 기준이며 중도 참여자의 연속 선택에서도 쓸 수 있고, 다른 사람에게는 보이지 않습니다.
   - **♻ 재충전**(방 설정에서 켠 경우): 네 번째 카드로 나옵니다. 고르면 새 증강 대신 사용 횟수가 줄어든 내 액티브 증강 1개를 처음 횟수로 되돌립니다(패시브 제외, 대상이 없으면 비활성). 대상을 고르지 않고 시간이 지나면 가장 많이 줄어든 증강을 되돌립니다. 하이리스크로 선택을 잃으면 함께 사라지고, 폭주기관차 다중 선택에서는 그중 1번만, 중도 참여자의 연속 선택에는 나오지 않습니다. 재충전 여부는 본인에게만 보이고 좌석의 증강 수도 그대로입니다.
4. 내 차례에 폴드/체크/콜/레이즈(슬라이더·½팟·팟)/올인. 보유 증강은 화면 아래 카드에서 사용합니다. 지금 쓸 수 없는 증강은 버튼이 비활성화되고, 마우스를 올리면 쓸 수 있는 시점이 보입니다.
   - **내 족보**: 손패 옆 패널에 지금 족보 이름과 강도 막대가 보이고, 족보를 이루는 카드는 금색 테두리, 키커는 흰 테두리, 안 쓰이는 카드는 어둡게 표시됩니다. 와일드 카드에는 **W**, 족보 역전 중에는 "낮은 패가 이깁니다"가 붙습니다. **족보표** 버튼으로 전체 서열과 내 증강의 변형 규칙을 볼 수 있습니다.
   - **채팅**: 대기실과 게임 화면(오른쪽 패널 "채팅" 탭, 모바일은 화면 아래). 새 메시지는 좌석 위 말풍선으로 잠시 뜹니다.
5. 칩이 0이 되면 탈락, 마지막 1인이 우승. 게임이 끝나면 방장이 같은 멤버로 대기실로 돌아갈 수 있습니다.

### 중도 참여
- 중도 참여가 켜져 있고 빈자리가 있으면 게임 중인 방에도 들어갈 수 있습니다. 관전하며 테이블의 공개 정보만 보고(참여 이전의 로그·다른 사람의 비공개 정보는 받지 않음), **다른 플레이어들이 지금까지 받은 증강 선택 횟수만큼** 연속으로 증강을 고릅니다(현재 레벨 별 확률, 선택마다 30초). 다 고른 뒤 **다음 핸드가 시작될 때** 자리에 앉습니다.
- 시작 칩은 방 설정의 시작 칩과 현재 생존자 평균 칩 중 작은 값이며, 은행에서 새로 지급합니다. 블라인드는 자리 순서대로 자연스럽게 돌아올 때 냅니다.
- 자동 상승 주기는 다음 레벨이 시작될 때부터 중도 참여자를 포함해 계산합니다. 탈락한 사람은 같은 토큰으로 다시 참여할 수 없습니다(리바이 없음).

### 추방
- 방장 화면에서 연결 끊김·자리 비움 좌석에 **추방** 버튼이 보입니다(확인 창). 접속 중인 플레이어는 추방할 수 없습니다. 자동 추방을 켜 두면 설정한 시간 이상 끊긴 플레이어가 자동으로 추방됩니다.
- 진행 중인 핸드는 폴드 처리되고 이미 낸 칩은 팟에 남습니다(보험 등 폴드 효과 없음). 핸드가 끝나면 자리에서 제거되고 남은 칩은 사라집니다. 그 사람이 선언한 지속 효과(죽음과 세금, 다음 핸드 암전)는 즉시 끝납니다.
- 추방된 토큰은 그 방에서 무효가 되어 재접속·재입장할 수 없습니다. 빈자리는 중도 참여로 채울 수 있습니다.

### 기본 규칙
- 시작 칩·블라인드·상승 주기·상승 방식은 방 설정을 따릅니다 (기본: 1,000칩, 10/20 → 20/40 → 40/80 → 75/150 → 150/300 → 300/600 → 600/1200 → 이후 2배씩, 그 레벨이 시작될 때 남은 인원 × 2핸드마다)
- 플랍·턴·리버 앞에 번 카드 1장씩. 보드 5장과 번 카드 3장은 핸드 시작 때 미리 떼어 둡니다.
- 2인일 때 헤즈업 규칙, 다중 사이드팟, 콜되지 않은 베팅 반환, 불완전 올인은 레이즈를 다시 열지 않음(TDA)
- 시간 초과: 체크 가능하면 체크, 아니면 폴드. 연결이 끊긴 채 **3핸드 연속**이면 자리 비움(블라인드만 내고 즉시 폴드)
- 방장은 접속 중인 다른 사람에게 직접 방장을 넘길 수 있습니다 (대기실 참가자 목록의 **방장 넘기기**, 게임 중에는 **방 설정** 창). 넘기면 채팅창에 알림이 뜹니다.
- 방장이 나가거나 끊기면 다음 순서의 접속 중인 플레이어에게 방장 권한이 넘어갑니다. 0명이 된 방은 바로 삭제됩니다.

## 증강 시스템

### 획득과 보유
- 별 확률: 1레벨 ★70/★★25/★★★5, 3레벨 40/45/15, 5레벨 이상 20/50/30 (2·4레벨은 앞뒤 평균)
- 선택지 3개는 같은 별에서 뽑고, 그 별에 고를 수 있는 증강이 3개 미만이면 **한 단계 낮은 별에서 채웁니다**.
- 같은 증강 중복 불가 · **배타적 풀(4장 플러시·징검다리·4장 스트레이트·짝수/홀수 동맹·보폭 두 배) 중 1개** · **방어/카운터형(역정보·방탄조끼·거울·카운터 스펠·역추적·철벽·면역·자물쇠·탈취·공개 청문회) 1개** · **불사의 토템과 3일 안에 오리라는 동시 보유 불가** · **증강 셔플은 게임 전체에서 한 명만**. 보유할 수 없는 증강은 선택지에 나오지 않습니다.
- 증강 풀은 1차 35개 + 2차 33개(죽음과 세금 포함) + 3차 39개 = 107개이며, 선택지는 모든 풀에서 함께 뽑습니다.

### 공개와 알림
- 보유 증강은 비공개이고, 좌석에는 보유 개수만 보입니다.
- **나만 정보를 얻는 정보형**(투시·예지·열화상 카메라·거짓말 탐지기·탐문·온도계·레이더·색채 예보·순위표·운명의 실), **블랙잭**, **내기할래?**, **공포탄**은 "○○님이 비공개 증강을 사용했습니다"로만 알립니다. 이 알림들은 문장·반응 대기 모습까지 완전히 같습니다.
- **데스티니 드로우**는 이름(사용 사실)만 공개하고 고른 카드는 비공개, **소문**은 누가 썼는지도 알리지 않고 익명 메시지만 띄웁니다.
- **턴과 리버 사이**는 사용 사실(이름)을 공개하고 본 카드는 비공개입니다.
- 예지·투시처럼 나만 알게 된 정보는 테이블 가운데에 큰 카드와 함께 몇 초간 크게 뜨고(눌러서 닫기), 오른쪽 "나만 아는 정보"에 증강 이름 태그와 함께 남습니다. 예지·턴과 리버 사이로 미리 본 보드 카드는 아직 공개되지 않은 보드 칸에 점선 카드로 표시됩니다.
- **지목형**(강제 집행·실명 다트·너 나가·눈싸움·명추리·기생)은 **철벽**으로, **강제 폴드**(러시안 룰렛·너 나가)는 **방탄조끼**로 막을 수 있습니다.
- 그 외 액티브·공개형 증강은 선언하는 순간 이름이 공개됩니다(위장이 준비되어 있으면 가짜 이름).
- 패시브는 효과가 처음 드러나는 순간 공개됩니다(보험 환급, 세 번째 손 버리기, 변형 족보·동점 처리가 쇼다운에 쓰일 때, 하이리스크, 방탄조끼). 관찰자·카운팅·거울·역정보·애착처럼 나만 아는 효과는 공개하지 않습니다.

### 반응 대기 (3초)와 카운터 스펠
- 액티브·공개형 증강이 선언될 때마다 효과 적용 전 **항상 3초** 기다리고, 테이블 중앙에 선언된 증강과 남은 시간이 보입니다.
- 이 시간 동안 카운터 스펠 보유자에게만 "무효화할까요?" 버튼이 보입니다. 보유자가 없어도 똑같이 3초 기다립니다(서버 타이머가 보유 여부와 무관).
- 무효화되면 선언자의 사용 횟수는 소모됩니다. 카운터 스펠 자체는 무효화할 수 없습니다.
- 여러 선언이 겹치면 선언 순서대로 각각 3초씩 대기 후 적용되고, 충돌하면 나중 효과가 우선합니다(예: 암전 중 유리 테이블).
- 반응 대기 동안 상황이 바뀌어 효과가 성립하지 않으면(예: 대상이 이미 폴드) 효과 없이 사용 횟수와 세금을 돌려줍니다.

### 선언 기회 (턴·리버 공개 직후)
턴 공개 직후(되감기), 리버 공개 직후·리버 베팅 전(되감기·봉인·밥상 뒤집기) 해당 증강을 가진 사람에게 **딜러 왼쪽부터 한 번씩** 선언 기회가 주어집니다. 다른 사람 화면에는 누가 결정 중인지 표시하지 않습니다.

### 보상 출처
"팟에서"는 현재 팟, "상대에게서"는 해당 상대의 칩(남은 칩 한도), "은행에서"는 새로 생기는 칩입니다. "은행에 낸다"(죽음과 세금의 세금, 나 다시 돌아갈래의 대가)는 칩이 게임에서 사라지는 것입니다.

#### 3차 증강 세부 해석
- **제안·입찰 응답** 중에는 그 차례였던 사람의 행동 시간이 멈췄다가 남은 시간부터 이어집니다(최소 5초). 응답을 기다리는 동안에는 베팅과 다른 증강 사용이 막힙니다.
- **골라 봐**: 시간 초과는 거절. 3BB가 없으면 있는 만큼 냅니다. **사채업자**·**대출**: 빌린 사람이 그전에 탈락(부활 대기 포함)·추방되면 빚은 사라집니다.
- **정보 경매**로 본 카드는 그대로 나오도록 고정됩니다(자석·되감기로 바뀌지 않음). 실명 다트 대상은 경매에 참여할 수 없고, 안경 효과 중 낙찰자는 숫자만 봅니다.
- **진실 게임**의 족보 종류는 실제 최종 족보(변형 포함) 기준이고, **눈싸움**은 쇼다운과 같은 판정으로 강약을 정합니다(동점이면 정산 없음).
- **밀봉 계약**: 핸드가 쇼다운으로 끝나면 "한 명 이상 콜", 쇼다운 없이 내가 이기면 "전원 폴드"로 봅니다. 내가 폴드하면 무효.
- **명추리**: 틀리게 부른 카드는 다른 사람의 카드일 수 있어 공개하지 않습니다. 모든 팟에 참여했다면 카드를 공개하지 않고 끝나고, 참여하지 못한 사이드팟만 쇼다운으로 판정합니다.
- **3일 안에 오리라**: 남은 사람이 1명이 되면 게임이 끝나고, 부활 대기자는 늦게 탈락한 순서대로 다음 등수가 됩니다. 순위 계산에서 부활 대기자는 아직 남은 것으로 셉니다.
- **증강 셔플**: 받는 사람이 보유 규칙에 걸리지 않는 조합을 찾을 때까지 다시 뽑고(최대 30번), 끝내 맞지 않는 사람은 넘기지 않습니다. 받은 증강은 비공개 상태가 됩니다.
- **잠복**: 얻는 순간 무작위 1개를 숨기고, 다음 핸드가 시작되기 전까지 증강 카드의 "숨기기"로 바꿀 수 있습니다.
- **운명 공동체**: 팀원은 쇼다운까지 남아 있어야 몫을 받고, 받는 몫은 팀원이 이번 핸드에 낸 칩까지입니다.
- **기록관**의 블러프는 리버에서 베팅·레이즈했는데 쇼다운 족보가 하이카드였던 경우입니다.
- **운명의 실**은 남은 보드를 모두 나열해 계산하고(플랍 기준 최대 990가지), 조합이 2만 가지를 넘으면(거꾸로 강을 거슬러 등) 고정 시드 2만 개 표본으로 계산합니다. 상대 패는 서버가 아는 실제 카드로 계산합니다.
- **재충전**의 대상 고르기는 증강 선택 제한 시간(30초) 안에서 진행합니다. 대상 고르기에 별도 타이머를 두면 다른 사람 화면의 대기 시간이 달라져 재충전 여부가 드러나기 때문입니다.

### 족보 판정 규칙
- 표준 홀덤 판정기 위에 플레이어별 변형(원형·4장 플러시·징검다리·편애)을 얹고, 겹쳐도 항상 그 플레이어에게 가장 높은 족보로 판정합니다. 봉인된 카드는 모두의 계산에서 빠집니다.
- **족보 역전**(밥상 뒤집기): 변형을 먼저 적용한 뒤 비교를 뒤집습니다(키커까지). 두 번 겹치면 상쇄.
- **동점 처리**(키커 장인·절대 키커)는 역전 중에도 "보유자가 이긴다"로 동작하고, 양쪽 모두 해당하면 상쇄됩니다.
- 쇼다운 결과 화면에는 각자의 최종 족보, 변형 족보 이름(4장 플러시, 징검다리 스트레이트, 원형 스트레이트, 와일드카드 사용), 적용된 증강, 동점 처리 승리, 그리고 상단에 테이블 효과(족보 역전·봉인·안개·유리 테이블·암전·되감기)와 양치기 소년 벌금이 표시됩니다.

### 명세를 구현하며 정한 세부 해석
플레이 테스트 후 바꾸기 쉬운 곳들입니다.
- **거짓말 탐지기**의 "메이드 핸드": 최선 5장이 원페어 이상이고 그 족보를 이루는 핵심 카드에 홀카드가 들어 있을 때 (보드 페어에 홀카드가 키커로만 붙은 경우는 아님). "직후"는 그 베팅·레이즈 뒤 아무도 행동하기 전까지(내 차례가 아니어도 사용 가능).
- **카운팅**의 "남은 카드"는 실제 덱이 아니라 **내가 모르는 카드**(상대 홀카드 + 덱)입니다. 실제 덱 구성을 보여 주면 상대 홀카드가 역산되기 때문입니다. 아웃츠는 다음 카드 1장으로 족보 종류가 올라가는 카드, 완성 확률은 플랍에서 턴·리버 2장의 모든 조합, 턴에서는 아웃츠/남은 카드로 계산합니다.
- **멀리건**이 카운터되면 1BB를 내지 않고 카드도 바뀌지 않습니다(이번 핸드 사용은 소모).
- **무임승차**: 절반(올림)만 내고 남은 금액은 "맞춘 것"으로 봅니다. 헤즈업이면 상대의 초과분이 콜되지 않은 베팅으로 돌아가고, 여러 명이면 그만큼 사이드팟으로 처리됩니다(무임승차한 사람은 낸 만큼만 팟 자격). 블라인드만 마주했을 때는 쓸 수 없습니다.
- **강제 집행** 대상은 그 리버 라운드에서 콜만 할 수 있습니다(레이즈·폴드 불가, 시간 초과 시 자동 콜).
- **양치기 소년**: 가짜 카드는 내 카드·보드·이미 공개된 카드와 겹칠 수 없고, 유리 테이블 중에는 쓸 수 없습니다. 벌금 2BB는 거짓말한 사람의 칩에서(남은 한도) 쇼다운에 함께 간 상대들에게 똑같이 나눕니다.
- **역정보**의 가짜 결과: 투시는 대상이 갖지 않았고 보는 사람이 모르는 카드, 열화상은 다른 하이/로우 개수, 거짓말 탐지기는 반대 결과.
- **러시안 룰렛** 대상이 방탄조끼를 가졌으면 조끼가 소모되고 아무도 폴드하지 않습니다. 강제 폴드도 보험 환급 대상입니다.
- **암전**은 핸드 사이(결과 화면·증강 선택 중)에만 선언해 다음 핸드에 적용됩니다. 암전 중 멀리건·세 번째 손은 무작위이고, 본인 화면에도 카드 뒷면만 보입니다.
- **유리 테이블**은 폴드한 사람의 카드도 공개합니다.
- **짙은 안개** 중 봉인은 카드 위치로 지정할 수 있고, 플랍을 못 보는 사람에게는 "보드 N번째 카드"로만 알립니다. 쇼다운 없이 끝나면 플랍은 끝까지 공개되지 않습니다.
- **봉인**은 보드가 3장 미만이 되지 않도록 한 핸드에 2장까지.
- **애착**: 고르지 않으면 높은 카드를 가져가고, 공개되지 않습니다.
- **면제권**은 블라인드 차례에 선언되어 반응 대기를 거칩니다(카운터되면 블라인드를 냄). 블라인드를 면제해도 그 핸드의 베팅 기준은 BB입니다.
- **죽음과 세금**: 면제권 발동·카운터 스펠·공포탄도 세금 대상, 패시브·자동 발동은 제외. 핸드 밖에서는 세금을 내고도 칩이 남아야 쓸 수 있고(핸드 중에는 남은 칩 전부까지, 0이 되면 올인 상태), 세금을 못 내면 면제권은 발동하지 않고 블라인드를 냅니다.
- **하이리스크**: 그 핸드 중 칩을 모두 건 적이 있으면 "올인". 받은 팟이 있으면 받은 금액의 20% 보너스.

#### 2차 증강 세부 해석
- **온도계**는 역정보·거울의 대상이 아니고(명세의 목록대로), 역추적에만 잡힙니다. **레이더**는 폴드하지 않은 상대만 셉니다.
- **순위표**는 쇼다운과 같은 판정(변형·블랙잭·순혈·동점 처리·족보 역전)으로 등수를 계산합니다.
- **데스티니 드로우**: 다른 사람이 애착·보관함으로 가져가는 카드를 고르면 거절됩니다(어떤 카드인지는 서버만 앎). 선택 화면의 회색 카드는 내가 이미 가져가는 카드입니다.
- **보관함**: 폴드한 핸드가 끝날 때 보관할 카드를 고릅니다(안 고르면 높은 카드). 다음 핸드 프리플랍 동안 아무 때나 교체할 수 있고, 플랍이 깔리면 사라집니다. 교체는 패시브라 알림·세금이 없습니다.
- **양자택일**: 플랍 직후 선언 기회에 선언 → 반응 대기 후 후보 2장이 보이고, 턴이 공개되기 전까지 고르면 됩니다(베팅은 계속 진행). 고르지 않으면 원래 턴 카드.
- **블랙잭**: 리버 직후 선언 기회에 21을 만들 수 있을 때만 선택지에 나옵니다. 발동 후 쇼다운에서 다시 계산합니다(되감기 등으로 보드가 바뀌면 21이 아닐 수 있음).
- **순혈**: 역전 중에도 동점 처리 증강처럼 "보유자가 이긴다"로 동작합니다.
- **동맹 플러시**: 같은 숫자가 겹쳐도(페어 포함) 5장이 모두 고른 쪽 숫자면 인정합니다.
- **서킷브레이커**: 라운드 시작 시점(프리플랍은 블라인드 포함)으로 각자의 베팅을 되돌리고, 폴드한 사람은 그대로 폴드입니다. 다시 시작한 라운드는 레이즈 1번(올인 레이즈 포함) 뒤에는 콜·폴드만 됩니다.
- **내기할래?**: 우승 족보는 메인팟 승자의 최종 족보(포카드 이상은 하나로). 환급은 분배 전 팟에서 빼서 돌려줍니다.
- **왕귀**: 쇼다운 없이 이긴 팟도 "이긴 것"으로 봅니다. 3번 미만에서 이기면 횟수는 0으로.
- **쇼맨십**: 핸드가 끝난 뒤 공개 여부를 고릅니다(시간이 지나면 공개 안 함). 블러프 판정은 그때까지 공개된 보드 기준.
- **면역**: 반응 대기 중 카운터 스펠처럼 즉시 적용(별도 반응 대기 없음). 죽음과 세금이면 그 선언자 몫의 세금만 면제됩니다.
- **자물쇠**는 그 라운드의 첫 베팅 행동 전에만 선언할 수 있고, 반응 대기 중 이미 선언된 다른 증강은 그대로 처리됩니다(그 반응 대기에는 카운터 스펠 불가).
- **폭탄 팟** 핸드는 블라인드가 없어 면제권·모범납세자가 쓰이지 않습니다. 앤티는 "블라인드"로 취급되어 나 다시 돌아갈래에서 돌려주지 않습니다.
- **실명 다트** 대상에게는 보드, 보드 카드가 담긴 로그(플랍·턴·리버·되감기·봉인), 현재 족보, 카운팅을 보내지 않으며, 예지·색채 예보·레이더·순위표·블랙잭·양자택일을 쓸 수 없습니다. 쇼다운 없이 끝나면 보드는 끝까지 보이지 않습니다.
- **하이카드**: 사이드팟 없이 팟 전체를 가장 높은 카드 주인이 가져갑니다(동점은 분배).
- **나 다시 돌아갈래**: 폴드한 사람도 새 카드를 받아 다시 참여합니다. 이번 핸드의 카드가 담긴 로그와 모든 사람의 이번 핸드 메모를 지우고, 공개형 효과(언더독·폭탄 팟 제외)는 사라집니다. 멀리건 비용은 돌려주지 않습니다.

## 보안 설계

- 덱, 번 카드, 다른 사람의 홀카드, 공개 전 보드, 다른 사람의 비공개 증강, 반응 대기 중인 남의 비공개 선언 내용은 서버의 `GameState` 에만 있습니다. **`GameState` 는 서버 밖으로 나가지 않고**, 서버는 각 소켓에 `getPlayerView` 결과만 **개별 전송**합니다.
- 투시·예지·관찰자·열화상 카메라·거짓말 탐지기·카운팅·탐문·거울 결과는 서버에서 판정해 해당 플레이어의 뷰와 그 사람만 보는 로그에만 들어갑니다.
- 짙은 안개로 가려진 플랍, 암전 중 본인 카드도 서버가 뷰에서 빼고 보냅니다.
- 모든 행동은 서버에서 검증합니다: 차례, 금액, 증강 보유·남은 횟수·사용 시점·대상, 세금 납부 가능 여부.
- 셔플은 Web Crypto + 거절 샘플링 Fisher–Yates. 8인 전원이 세 번째 손·멀리건·되감기를 가져도 필요한 카드(5+3+24+8+8=48장)가 52장 이내인지 핸드 시작 시 확인합니다.
- **디버그 기능**은 `DEBUG=true` 일 때만 서버가 디버그 이벤트를 **등록**하고, 엔진도 debug 게임에서만 실행합니다(이중 차단).

### 직접 확인해 보기 (개발자 도구)
Network → `socket.io` WS → Messages 의 `game` 메시지에서 `view.you.hole` 에는 내 카드만, 다른 사람 `players[].shownCards` 는 쇼다운·유리 테이블 전까지 `null`, 다른 사람 증강은 `augmentCount` 와 공개된 것만, 비공개 증강 선언은 `reaction.label` 이 "비공개 증강"으로만 옵니다.

## 디버그 모드 (`DEBUG=true`)

게임 화면 오른쪽 아래 **디버그** 패널에서:
- **모든 카드·증강 공개**: 모든 홀카드·버린 카드·애착 카드, 전체 보드·번 카드, 덱 순서, 모든 증강(남은 횟수·공개 여부·위장·면제권), 반응 대기 중인 선언의 실제 증강
- **증강 지급** (편애는 와일드 숫자 지정 가능), **칩 설정**, **블라인드 레벨 즉시 올리기**(다음 핸드부터 한 단계 + 증강 선택)
- **다음 핸드 카드 지정 / 덱 순서**: 보드(최대 5장), 번 카드(최대 3장), 플레이어별 홀카드(예: `As Kd`), 남은 덱 맨 위부터의 순서(멀리건·되감기에 쓰임)
- **선택한 플레이어 연결 끊기**: 그 창의 연결을 서버가 끊습니다(그 창에서 "다시 연결"을 누르기 전까지 끊긴 상태). 자리 비움·추방 테스트용

게임이 끝나면 서버 콘솔에 **통계**(총 핸드 수, 재충전 켜짐/꺼짐, 증강별 선택·사용 횟수, 은행에서 생성된 칩 총량(증강 보너스·대출·중도 참여 지급), 은행으로 빠진 칩 총량(세금·상환·수수료), 추방으로 사라진 칩, ★★★ 증강 총 사용 횟수, 메이드 인 헤븐 중 시간 초과 자동 폴드 횟수, 플레이어별 재충전 횟수와 재충전한 증강 이름)가 출력됩니다.

증강 지급 시 짝수/홀수 동맹은 옆 입력칸에 `짝` 또는 `홀`을 넣으면 그쪽으로 지급됩니다(비우면 무작위). 디버그 전체 공개 화면에는 동맹 쪽, 보관 카드 등도 함께 표시됩니다.
